Step 4 of 4

Where to start

Good first projects are ones the model does well (high capability), carry low risk, and have answers that are easy to check. Switch each criterion on or off to see how the use cases rank.

Each task is scored on its own. Clicking a button changes only that task. Starting values are suggestions. Change them to match your own business.

What to remember

Match the model to the job, not to the headline. Start with a task that is frequent, forgiving and easy to review, learn from it, and then move to harder work.
