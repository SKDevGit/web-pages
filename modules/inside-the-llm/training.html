How training works

3 stages · 9 exercises

A language model isn’t given rules. It reads a very large amount of text and gradually adjusts itself until its guesses about what comes next get good. Here you’ll run that process yourself, one step at a time, on a model small enough to see.

By the end you candescribe the training loop, explain what an error score is, and say how a base model becomes an assistant and then a product.

The big picture

This is how a useful assistant is built, in simplified form. The page follows it in three stages: build a base model, turn it into an assistant, and package it as a product. Stage 1 of 3Base model

Steps 1 to 5. Run the training loop yourself: guess the next word, check the error, adjust the numbers, repeat. The result is a base model.

Base model · Step 1 of 5

Take a text example

Training starts with ordinary text. Take a sentence, hide the next word, and ask the model to guess it. The text provides its own answer key, because the word that really came next is the right answer.

Base model · Step 2 of 5

Let the model guess

The model holds a table of numbers called parameters. It uses them to give every word it knows a percentage chance of coming next. Early on those numbers are close to zero, so the guesses are close to random.

Base model · Step 3 of 5

Check the answer

Now reveal the real word and measure how surprised the model was. The error score is low when the model gave the right word a high chance, and high when it gave it a low chance. Training is the project of pushing that score down.

Base model · Step 4 of 5

Adjust the numbers

The model nudges its parameters so that, for this same context, the real word gets a little more chance. Each nudge is small on purpose, and training repeats it many times so the changes add up. The slider sets how big each nudge is: a bigger size moves the chance more in a single press, a smaller size moves it less. Press the button a few times and watch the chance climb.

Base model · Step 5 of 5

Repeat

One example teaches the model almost nothing. Training is this loop run over and over on different sentences, so the nudges add up. Run it in bulk and watch the error score fall.

Training repeats this loop over many different examples, and stops when the average error stops improving or the planned budget of data and computing is used up. It never reaches zero, because many endings are reasonable.

Stage 2 of 3Base model to assistant

Steps 1 to 3. A base model predicts the next token, so it simply continues text. Two more rounds of training, then a round of testing, turn it into an assistant people can use.

Base model to assistant · Step 1 of 3

Fine-tune on examples

A base model predicts the next token from patterns in its training text. So it simply continues whatever text it is given, and does not reliably treat a request as an instruction to follow. Fine-tuning shows it many example requests paired with good answers, using the same loop you just ran, so it learns to answer rather than continue. Base model to assistant · Step 2 of 3

Learn from human feedback

Fine-tuning teaches the format. Feedback teaches the quality. For each request the model writes two answers, and a person picks the better one. People’s choices are turned into a score for answers, and the model is adjusted toward higher-scoring ones. You are the rater: choose the better answer in each round.

Base model to assistant · Step 3 of 3

Test and release

Before release, the vendor runs the model through test requests, including tricky and harmful ones. Then the parameters are frozen and a version is published. Run each test, then release.

A model on its own is a file of numbers. A product wraps it with instructions, an interface, safety checks and sometimes tools. Chat assistants, coding assistants and agents are different packages around similar models.

What you’ve seen

Stage 1. Take an example, guess, check, adjust, repeat. Large models run the same loop, with far more text and far more parameters. Nothing in it tells the model what a customer or a refund is. Patterns in the text get stronger because they come up again and again. The result is a base model.

Stage 2. Fine-tuning on examples teaches it to answer instead of continue. Human feedback teaches it which answers people prefer. Testing checks it before the parameters are frozen and released.

Stage 3. A product wraps the model with instructions, an interface, safety checks and sometimes tools. The same kind of model can become a chat assistant, a coding assistant or an agent.
